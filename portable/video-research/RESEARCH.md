# Research snapshot and adoption boundaries

This package is research/setup-only. Production approval remains separate. The target machine was reported by the user as RAM 32 GB, Intel Core i5 generation 8 and GTX 1070 Ti. No target benchmark, driver probe or GPU render has been performed. Do not carry performance conclusions from an older machine into this target.

## Three distinct execution lanes

1. Structured 3D: versioned Blender scene/mesh/material/rig/camera/timing, with mechanical/domain checks.
2. Generative footage: Google Flow or Seedance via an exact supported account/platform/model route, with real reference attachment.
3. Finishing: approved narration, captions, compositing, color and full audiovisual QA.

Agy is the coding/authoring worker; MCP is an optional control bridge, not a rendering accelerator. Higgsfield can supply TTS/sandbox/GPU rental and is not synonymous with a video model. Local-first is the cost-control preference; cloud GPU is optional after measured need, rights review, quote and approval.

## Flow / Seedance controls

Canonical local sources do not make native Character/voice IDs portable. Validate role/media/mode support and actual attached references on each route. Unknown limits are UNKNOWN. Keep provider wallets, consent/trust provenance, quote, output count and approvals separate. Do not silently remove references or switch models/providers when credits run out. A timeout after submission is UNKNOWN until reconciled; never blindly resubmit.

The files in research/ contain the detailed prior plan, contracts and proposed test matrix. Those tests remain proposed/NOT_RUN; tests of the portable sync helper do not validate generation quality or platform access. Source retrieval dates are not publication dates. Refresh time-sensitive model, billing and policy claims before using a service.

## What can be restored from this repo

Two authored skills and their references/templates are bundled with exact hashes. The selected settings snapshot is a field-level migration baseline, not a whole-profile backup. External skills from the root engineering catalog, paid integrations, browser sessions, installed apps and accounts are intentionally outside this bundle. Do not promise a fully identical runtime or rendered output based on matching config files alone.
