00-README

CREATOR DESKTOP — PAKET RENCANA v0.2
Tanggal: 28 November 2026, UTC+07:00
Status: PROPOSED / BELUM DISETUJUI UNTUK IMPLEMENTASI
Nama kerja: Creator Desktop; bukan nama produk yang sudah diputuskan.
Pemilik produk/pemberi persetujuan: ayah keren.

1. RINGKASAN
Aplikasi desktop Windows-first dengan Rust sebagai domain core dan Tauri sebagai shell yang diusulkan. Aplikasi mengubah brief dan aset menjadi rencana video, menjalankan workflow terkontrol melalui adapter/API/MCP/Chrome yang tersedia, lalu mengomposisi, meninjau dan mengekspor hasil.
Fokus vertical slice pertama: affiliate Shopee Indonesia AI-assisted/hybrid berbasis produk/varian nyata dan aset berizin. Blender bukan default affiliate; structured 3D engineering menjadi lane terpisah dengan Blender atau Three.js sesuai kebutuhan.
Shopee menjelaskan program affiliate melalui media sosial, Shopee Video dan Shopee Live; paket ini memilih video dan export manual, bukan live commerce.[12]

2. KEPUTUSAN DESAIN INTI — MASIH USULAN
  Tujuan: AFFILIATE, EDUCATIONAL, STORYTELLING, GENERAL.
  Format: SHORT, LONG, CUSTOM — terpisah dari tujuan.
  Platform output: Shopee Video, TikTok, YouTube Shorts/Video, Instagram Reels, Custom.
  Gaya produksi: product footage, product explainer, narrative/B-roll, motion graphic; 3D engineering kemudian.
  Template: mengunci workflow version, skill revisions, kebutuhan aset, opsi konfigurasi dan QA.
Contoh valid: AFFILIATE + SHORT + Shopee Video + Product Explainer.
Contoh valid: EDUCATIONAL + LONG + YouTube + Engineering 3D.
Sidebar boleh menyediakan shortcut Affiliate / Short / Video Biasa, tetapi shortcut tidak menjadi enum kategori yang saling meniadakan di database.

3. APA YANG SUDAH DIKETAHUI
  User ingin desktop berbasis Rust, MCP/adapter/Chrome, template routing, setting video, menu provider/model dan pemilihan model pada generator.
  Konteks konten: Shopee Indonesia; distribusi juga TikTok, YouTube dan Instagram.
  Skill editorial affiliate dan skill setup 3D sudah ada dalam pekerjaan sebelumnya. Skill bukan renderer, koneksi provider, maupun bukti aplikasi siap berjalan.
  Aplikasi ini belum dibangun. Tidak ada login, upload aset, render produksi atau kredit dipakai dalam pekerjaan perencanaan ini.

4. ASUMSI UNTUK DISETUJUI
  Single operator, single local workspace aktif, offline-first untuk metadata dan editing rencana.
  Windows menjadi target pertama; target hardware lama adalah laporan pengguna, bukan hasil benchmark aplikasi ini.
  UI web dalam Tauri diperbolehkan; “Rust desktop” bukan berarti semua UI harus pure Rust.
  Tidak ada akun cloud milik aplikasi, subscription server, kolaborasi multiuser atau marketplace plugin pada MVP.
  API resmi diprioritaskan; Chrome assistant bersifat opt-in. Tidak mengasumsikan akses Shopee OpenAPI/affiliate API atau Google Flow API tersedia.

01-PRD

PRD — CREATOR DESKTOP v0.2
Status: usulan; belum aplikasi berjalan. Sumber kebutuhan utama: permintaan ayah keren.

1. MASALAH DAN OPPORTUNITY
Saat ini brief, produk, aset, skill, provider AI, browser dan renderer terpisah. Risiko: produk/varian tertukar, klaim tidak berdasar, pilihan model tidak mendukung referensi, workflow dipilih berdasarkan nama skill saja, biaya tidak terlihat dan hasil tidak memiliki jejak asal.
Hipotesis produk: satu workspace yang mengikat semua itu mengurangi kerja ulang dan kesalahan. Belum ada user study atau benchmark yang membuktikan penghematan waktu atau peningkatan komisi. Jangan memakai “viral” atau “menguntungkan” sebagai acceptance teknis.

2. USER DAN JOB TO BE DONE
Persona primer: kreator/affiliate solo yang memiliki link produk, aset sendiri/berizin, akun layanan sendiri, dan ingin membuat beberapa format tanpa mengatur ulang tool dari nol.
Job primer: “Pilih produk yang tepat, buat naskah yang jujur, gunakan aset produk yang sesuai, pilih tool/model yang bisa memenuhi brief, review, lalu dapatkan paket video siap diperiksa sebelum posting.”
Persona sekunder: pembuat educational/narrative content. Engineer 3D adalah lane terpisah, bukan prasyarat affiliate.
Aktor pendukung: penyedia AI, MCP server, Chrome extension/host, filesystem dan compositor lokal. Mereka bukan pengguna yang berhak memberikan persetujuan bisnis.

3. OBJECTIVES DAN PENGUKURAN
  O1 Menghasilkan satu proyek affiliate yang dapat ditelusuri dari produk/varian sampai file export.
     Ukur: seluruh klaim yang tampil punya evidence dan approval; seluruh aset punya hak penggunaan yang ditinjau.
  O2 Memilih jalur yang kompatibel tanpa mengubah kebutuhan diam-diam.
     Ukur: semua negative capability cases menghasilkan BLOCKED dengan alasan, bukan submit terdegradasi.
  O3 Aman dilanjutkan setelah crash atau timeout.
     Ukur: fault-injection tidak membuat dispatch ulang untuk intent UNKNOWN.
  O4 Membuat konfigurasi provider/model bisa dipahami.
     Ukur: user dapat membedakan terdaftar, terhubung, teruji dan berhak generate dalam usability pilot.
  O5 Mengurangi waktu kerja ulang.
     Ukur: bandingkan waktu operator dan accepted-shot cost pada task yang sama dengan proses manual; target angka ditetapkan setelah baseline.
Outcome bisnis lanjutan: komisi tervalidasi, biaya produksi, conversion bila tersedia. View count tidak menggantikan revenue evidence; hasil belum dapat dijanjikan.

4. TAKSONOMI PRODUK
Jangan membuat kategori Affiliate vs Short vs Video Biasa sebagai tiga pilihan eksklusif.
  Intent = tujuan konten.
  Format = short/long/custom + durasi target.
  Platform = tujuan export/policy profile.
  Style = gaya produksi.
  Template = resep versioned yang kompatibel dengan dimensi di atas.
  Project = instance brief + settings + produk/aset.
  Run = eksekusi rencana yang telah disnapshot dan disetujui.
Pilihan model dilakukan per tahap (planner/vision/image/video/voice), bukan satu model yang diasumsikan bisa semua. Renderer FFmpeg/Blender bukan model AI.

5. CORE FEATURES
  Project Studio: brief, bahasa, tujuan, format, platform, template, output settings.
  Product Library: link produk, seller, item identifier bila terverifikasi, varian, spesifikasi, sumber dan waktu observasi.
  Evidence & Asset Library: foto/video asli, rights review, voice/likeness consent, claim-to-evidence map, versi immutable.
  Templates & Workflows: packaged read-only presets, version pins, DAG, required inputs, human gates.
  Providers & Models: provider instances, adapter/protocol support, credential reference, model catalog, role/capability matrix, test status.
  Connections: MCP transport, Chrome pairing/tab consent, dependency diagnostics; tidak menyamakan connected dengan safe-to-generate.
  Generator: scene plan, selected routes, reference binding, estimated costs/units, prepare/readback, approval.
  Jobs & Recovery: queue, node state, immutable intent, event log, pause/cancel, reconcile unknown results.
  Finishing & QA: trim/order, captions/narration/music authorized, export preset, product-fidelity review, technical probe/full decode.
  Export Center: MP4, captions, approved caption/CTA text, product/affiliate link, provenance report dan posting checklist.
  Settings: project/global settings terpisah, budgets, allowed paths/endpoints, privacy, retention, preview quality, backups.

6. AFFILIATE SHOPEE: DOMAIN RULES
Wajib ada produk yang dipromosikan, tetapi tidak selalu harus memegang sampel fisik. Kebutuhan sampel/rekaman nyata bergantung pada jenis klaim dan template. Demonstrasi hasil/ulasan pemakaian harus didukung bukti nyata yang sesuai, bukan video AI yang berpura-pura sebagai pengalaman pribadi.
Link produk saja bukan izin memakai semua media seller. Imported seller image berstatus REVIEW_REQUIRED sampai hak komersial dan scope pemakaian ditinjau.
Data wajib: marketplace=SHOPEE_ID, judul, seller/display identity, product URL, varian yang dipilih (atau single-variant yang dikonfirmasi), claim evidence, aset produk, rights review.
Attribution mode dipilih eksplisit: EXTERNAL_LINK memakai affiliate link yang dimasukkan/diverifikasi user; PLATFORM_PRODUCT_TAG memakai pemasangan produk native saat posting manual. Canonical product URL tidak boleh otomatis disebut affiliate tracking link atau menjamin komisi. Jangan mengarang kode affiliate atau status keanggotaan.
Nomor item/shop hanya diisi bila sumber benar-benar memberikan; jangan menebak dari shortlink. Resolusi shortlink harus tervalidasi, membatasi redirect dan tidak mengambil cookie.
Harga, promo, stok dan komisi adalah snapshot berwaktu, nullable bila belum diketahui. MVP default tidak menampilkan angka harga/promo agar tidak mengarang atau cepat basi. Jika dipakai, perlu sumber, timestamp dan expiry; expiry tidak disamakan untuk semua marketplace.
Shopee mendokumentasikan penambahan produk ke video pada langkah posting. File MP4 dan teks URL yang diekspor aplikasi tidak otomatis membuat product tag/keranjang di Shopee.[11]
Kebijakan Shopee yang diambil membedakan kewajiban Label AI dari tambahan disclosure manual; release checklist harus mengingatkan operator mengaktifkan pengaturan platform ketika diwajibkan, bukan menganggap caption “AI” sudah cukup.[14]

7. TEMPLATE CATALOG YANG DIRENCANAKAN
M0 — PRODUCT_AI_HYBRID_EXPLAINER v1 (DEFAULT)
  Produk: 1 produk/varian; foto/video canonical dengan izin dan facts verified. Footage rekaman sendiri tidak wajib untuk factual explainer, tetapi klaim penggunaan/hasil aktual harus didukung bukti yang sesuai.
  Tahap: evidence/rights review -> AI script/storyboard -> exact route/capability/quote -> approval upload/generation -> reference-conditioned visual atau AI background/B-roll + product composite -> voice/captions -> compose -> QA -> export.
  Satu exact generative video route menjadi acceptance MVP; tidak dianggap selesai hanya dari model dropdown, mock result atau export slideshow. Jika automation belum aman, tampilkan manual-assisted handoff secara jujur dan jangan mengklaim automatic generation terverifikasi.
  AI host/karakter boleh sebagai penyaji dengan hak/consent/disclosure sesuai; tidak boleh menjadi fake testimonial atau demonstrasi palsu. Produk tidak boleh berubah. Preview rendah dan final spec tetap dipilih user.
M0 — PRODUCT_EXPLAINER_REAL_FOOTAGE v1 (ALTERNATIF)
  Footage asli/berizin tetap dapat memakai core yang sama untuk bukti hands-on dan detail produk. Blender tidak menjadi syarat salah satu template affiliate.
M0 — GENERAL_NARRATED_SHORT v1
  Memakai core yang sama, produk opsional, tetap butuh asset rights dan factual review bila menyampaikan fakta.
M1 — PRODUCT_STILL_MOTION v1
  Animasi crop/pan/fakta dari foto berizin. Label “product explainer”, bukan hands-on review. Jangan mengklaim memenuhi penilaian kualitas platform hanya karena export sukses.

  Produk canonical tidak boleh berubah; komposit diperiksa manusia. Jika model tidak menjaga bentuk/label/varian, pilih compositor berbasis aset asli atau BLOCKED.
M2 — NARRATIVE_MULTI_SCENE / ENGINEERING_3D
  Aset karakter/lokasi/voice atau mesh/rig/material versioned, gates tambahan. Engineering memakai Blender atau Three.js yang dipilih per shot; bukan “pakai semua engine sekaligus”.

8. SCOPE PRIORITY
M0 (MVP release candidate): project/product/assets/evidence, locked AI/hybrid affiliate template, provider/model menu, satu text route dan satu exact generative video route yang dipilih setelah spike, workflow runner, Chrome read-only/manual-assisted sebelum automation gate lolos, satu MCP diagnostic connection yang ditinjau, FFmpeg finishing, approvals, durable recovery, product-fidelity QA/export dan backup.
UI lengkap tidak berarti semua provider production adapter tersedia. Registrasi provider dengan protocol yang belum didukung harus menampilkan UNSUPPORTED, bukan tombol Generate palsu.
M0 generation gate: exact video route membutuhkan asset binding + live capability/quote + upload consent + reconciliation; API atau UI dipilih setelah spike. Jika Chrome prepare tidak bisa dibuktikan aman, gunakan manual-assisted dan laporkan batas automation.
M1: perluas template dan adapter setelah route pertama lulus pilot dengan output nyata dan biaya semua percobaan tercatat.
M2: template authoring terkontrol, batch/A-B variants, 3D/Blender, analytics imports dengan provenance, adapter tambahan.
Out of scope awal: auto publish Shopee/TikTok/YouTube/Instagram; API scraping tanpa izin; CAPTCHA/anti-bot bypass; cookie export; cloud GPU auto-rental; plugin arbitrary code; marketplace; team/cloud sync; e-commerce order/payment management; full professional NLE editor.

9. MVP RELEASE ACCEPTANCE
Satu project affiliate AI/hybrid dapat dibuat dengan produk/aset yang sah, review script/scene, generation melalui satu exact approved route dengan reference readback, compose lokal, lalu actual export/probe/full decode dan audiovisual/product-fidelity review. Tidak ada generation dalam tugas perencanaan ini.
Bukti produk yang hilang memblokir final export; bukti klaim yang hilang memblokir approval naskah.
Satu model incompatible, stale quote, revoked asset, wrong variant dan changed settings masing-masing menggagalkan preflight pada tes.
Crash setelah dispatch eksternal menjadi UNKNOWN dan tidak auto-retry. Cancel lokal tidak boleh menyatakan biaya provider berhenti.
Tidak ada secret di SQLite, log, backup proyek atau frontend store. Tidak ada operasi generation/upload/publish saat “Test connection”.
Hasil visual/audio dan konten tetap harus ditinjau operator; checker teknis tidak membuktikan kebenaran demo produk atau keuntungan affiliate.

10. TRADE-OFF DAN RISIKO BISNIS
Aplikasi orchestrator dapat berubah menjadi wrapper besar tanpa produk yang bagus. Karena itu vertical slice produk-ke-export didahulukan daripada puluhan model/MCP.
Kelebihan Rust: domain core terstruktur dan integrasi native; tidak menjamin adapter browser stabil atau rendering lebih cepat. Biaya maintenance tiap provider dan perubahan UI harus dimiliki jelas.
Official Shopee qualitative guidance menekankan produk terlihat jelas, informasi detail, kualitas audio/visual dan konten original. Tidak ada dasar untuk menjamin video AI atau slideshow otomatis lolos penilaian atau menghasilkan komisi.[13]
Preferensi user adalah AI/hybrid untuk affiliate. Klaim “lebih diterima audiens” tetap hipotesis; bandingkan hasil aktual, kejelasan produk, kualitas dan outcome tanpa menganggap engine menentukan penerimaan.

FUNCTIONAL SPEC — FLOWS & USE CASES v0.2

3. UC-01 SETUP WORKSPACE / FR-01,20,21,22
Precondition: app baru dibuka atau workspace dipilih.
Main: pilih root data lokal -> lihat izin path dan ruang bebas -> pilih bahasa/default output/preview -> set backup destination -> tampilkan workspace readiness.
Failure: direktori read-only/remote sync -> jelaskan dan pilih folder lain. File obstruction/path escape ditolak. Tidak auto migrasi profil Hermes.
Postcondition: workspace id dan setting valid tersimpan; belum ada provider terhubung.

4. UC-02 TAMBAH PROVIDER DAN MODEL / FR-07,08,10,17
  Pilih adapter/protocol yang didukung -> beri nama provider/account alias -> endpoint divalidasi -> secret disimpan melalui credential broker OS -> Test metadata connection (scope terlihat) -> pilih model dari discovery bila ada atau masukkan exact identifier manual -> deklarasikan capability -> test read-only/fixture yang relevan -> simpan.
  Catalog status: REGISTERED, CONNECTED, CAPABILITY_UNVERIFIED, VERIFIED, DEGRADED, UNSUPPORTED.
  Manual model entry diperbolehkan tetapi bukan bukti capability. Browser route memilih label/model yang terbaca di UI, bukan ID API yang dikarang.
  Set default model per role. Pengaturan default tidak mengubah run yang sudah dibuat.
Alt: generic compatible endpoint beda contract -> adapter reports CONTRACT_MISMATCH; jangan mengatakan connected karena HTTP 200 saja.
Alt: tidak ada discovery endpoint -> input manual + verified capability evidence setelah pilot.
Secrets tidak tampil di daftar/model picker/log. Hapus provider yang direferensikan run lama = disable, bukan cascade delete.

5. UC-03 BUAT PROJECT / FR-01,02,03,20
  New Project -> tujuan konten -> platform -> format/durasi -> jenis/gaya -> template kompatibel -> project name/brief/bahasa/CTA -> output aspect/resolution/fps -> product step bila affiliate -> simpan draft.
  Shortcut “Affiliate” membuka wizard dengan intent AFFILIATE; “Short” mengisi format SHORT; “Video Biasa” memilih GENERAL. User masih dapat membuat affiliate short maupun affiliate long.
  Preset boleh di-override dengan validasi; platform-specific duration/resolution limits harus punya source/version dan diperbarui, bukan dianggap universal.
  Global defaults < template defaults < project overrides < reviewed scene overrides; konflik hard requirement template tidak dapat di-override tanpa mengganti template/version.

6. UC-04 TAMBAH PRODUK DAN BUKTI / FR-04,05,06
  Paste link atau input manual -> confirm domain/market -> isi judul/seller/varian -> import aset berizin -> record source/owner/license/consent -> review candidate facts -> approve claims -> link project ke exact product version.
  Input minimal boleh tersimpan sebagai draft; generate final script dan export affiliate diblokir sampai mandatory fields terpenuhi.
  URL/import page berstatus UNTRUSTED_DATA. Teks seller tidak pernah menjadi instruksi tool.
  Produk baru dari versi lama tidak menimpa run historis. Perubahan harga/varian menambah product version dan invalidates dependent approvals.
Alt: shortlink unresolved -> user membuka sendiri lalu menyalin canonical URL; jangan meminta cookie/password.
Alt: aset rights belum jelas -> dapat menginventaris draft, tidak boleh upload/generate/export final dengannya.
Alt: tidak punya sample -> pilih product explainer berbasis facts, bukan template review pengalaman/demonstrasi hasil.

7. UC-05 BRIEF -> SCRIPT -> STORYBOARD / FR-09,11,12
  Core resolve template/workflow/skill versions -> build evidence pack -> operator pilih model planner -> tampilkan estimasi scope/biaya termasuk text call -> approval bila data dikirim/biaya -> planner menghasilkan typed proposal -> validate -> editor script dan claim references -> review -> scenes.
  Setiap scene memiliki narration/text, durasi estimasi, visual source, product/asset binding, locked attributes dan intended changes.
  AI “review saya setelah 7 hari” tidak boleh otomatis lolos; klaim pengalaman harus punya rekaman/bukti yang sesuai atau ditolak.
  Character/background/product/voice adalah peran aset berbeda. Nama aset di prompt tidak menggantikan binding file/version.

8. UC-06 PREFLIGHT, PREPARE DAN GENERATE / FR-10,12,13,14,17,22,27
  Select role routes -> hard constraints filter -> user memilih dari compatible routes -> resolve references -> inspect live capability/context -> classify effects -> jika upload perlu approval upload terpisah -> prepare -> read back provider state -> show settings/reference/quote receipt -> approve exact request -> reserve budget+consume grant+persist intent atomically -> dispatch once -> track/reconcile -> download and validate -> human QA.
  Effect classes: READ_LOCAL, READ_REMOTE, UPLOAD, PAID_GENERATION, LOCAL_RENDER, PUBLISH, ARBITRARY_EXEC.
  Test connection hanya metadata read; prepare yang memindahkan data tidak otomatis termasuk read-only. Tool annotations tidak menggantikan registry effect policy.
  Jika harga tidak diketahui: tidak membolehkan arbitrary spend; user dapat menyetujui bounded maximum dengan quote basis yang sah untuk API metered, atau route BLOCKED. UI route butuh quote/readback yang bisa diperiksa.
  Jika Chrome tab berganti URL/project/account/model -> revoke prepared receipt dan grant. Satu controller/lease per tab.
  UI prepare otomatis tetap disabled sampai accidental-submit prevention teruji; manual-assisted path tetap tersedia.
Alt: required product reference unsupported -> BLOCKED. Tidak menurunkan requirement menjadi text prompt.
Alt: grant expired atau payload berubah -> minta approval baru, bukan reuse.
Alt: timeout setelah dispatch -> UNKNOWN, keep reservation -> reconcile; tidak auto retry/reroute.

9. UC-07 FINISHING & REVIEW / FR-15,18
  Select approved source clips -> arrange/trim -> recorded narration/TTS output authorized -> captions -> music with rights -> preview -> correct -> export candidate -> technical checks -> watch audiovisual review -> release decision.
  Checks teknis: actual codec/container, dimensions/aspect, timestamps/duration, missing media, decode errors; loudness/black/freeze checks menjadi warnings dengan sampling disclosed.
  Checks manusia: product geometry/label/warna/varian, klaim benar, visual bukan demo palsu, suara/caption jelas, consent/disclosure sesuai.
  Product fidelity score/vision similarity adalah triage; tidak boleh otomatis menggantikan review audiovisual manusia.
  REVIEW_FAILED -> edit/re-render local, atau generate baru dengan intent/approval/budget baru. Output lama dipertahankan.

10. UC-08 EXPORT DAN POSTING MANUAL / FR-19,26
  Pilih attribution mode. External link memerlukan affiliate URL dan sumber/verifikasi user; native platform tagging memerlukan langkah manual di akun yang memenuhi ketentuan. Link produk biasa bukan otomatis link affiliate.
  Setelah QA pass -> export MP4 + SRT/VTT bila dipilih + approved caption/CTA + affiliate/product links + release report.
  User membuka aplikasi/platform tujuan sendiri, memasang product tag/keranjang dan disclosure melalui fitur resmi, lalu opsional mencatat published URL manual.
  Status EXPORTED tidak diubah menjadi PUBLISHED atau MONETIZED tanpa evidence terpisah. Auto publish = M2+/out of scope M0.

11. UC-09 RECOVER / CANCEL / FR-16,17,21
  Startup scans non-terminal runs -> local running processes re-check -> externally dispatched intents unresolved = RECONCILE_REQUIRED -> check status read-only on same scoped route/account -> associate existing output -> reconcile cost -> resume safe dependent nodes.
  User pause stops scheduling new nodes; tidak menjamin provider berhenti.
  Cancel remote = CANCEL_REQUESTED sampai provider readback confirms. Kalau API tidak mendukung cancel, jangan memalsukan cancellation success.
  Disable connection stops new dispatch; unresolved job tetap dapat dipulihkan lewat approved diagnostic/reconnect.

12. UC-10 SHORT/GENERAL/3D DAN ANALYTICS / FR-23,24,25
  Template lain memakai core yang sama, tetapi mengubah required inputs, adapters dan QA. Educational tidak memerlukan product; affiliate selalu memerlukannya.
  3D mengunci mesh/material/rig/camera/timing, dependency check dan domain QA. Blender dipakai untuk scene/offline render dan Three.js untuk procedural/interactive scene sesuai kebutuhan, dengan export timing/capture teruji; bukan image-to-video dengan nama “engineering”.
  Import analytics berisi source/date/window/cost/commission state; jangan menghitung profit dari views atau estimated unpaid commission saja.
  M2 template editor hanya memakai allowlisted node types, tidak menjalankan arbitrary shell dari teks skill.

13. STATE MACHINES
Project: DRAFT -> INPUTS_READY -> PLANNED -> REVIEWING -> READY_TO_EXECUTE -> PRODUCING -> READY_FOR_QA -> EXPORTED -> ARCHIVED.
  REVISIONS_NEEDED dapat kembali ke input/plan; run historis immutable. Status project adalah agregat UI, bukan sumber kebenaran transaksi job.
Node: PENDING -> BLOCKED/READY -> WAITING_APPROVAL -> RUNNING -> SUCCEEDED/FAILED/UNKNOWN/CANCEL_REQUESTED/CANCELED.
  UNKNOWN hanya keluar melalui reconciliation yang berbukti atau manual resolution yang diaudit; tidak langsung READY.
  Hanya local deterministic nodes tanpa side effect eksternal yang boleh retry otomatis dengan bounded policy.
Asset rights: REVIEW_REQUIRED -> APPROVED -> REVOKED. Revocation menghalangi new runs/final exports terkait, tidak menghapus audit history.
Approval: ISSUED -> CONSUMED atau EXPIRED/REVOKED. Perubahan material membuat approval tidak sah meski belum expired.

14. SCREEN STATES DAN AKSESIBILITAS

03-ARCHITECTURE

TECHNICAL DESIGN & STACK — v0.2
Semua keputusan di bawah adalah proposal; belum dependency/runtime terpasang atau benchmark.

1. PILIHAN ARSITEKTUR
Modular monolith local-first, satu Rust domain core, Tauri UI, subprocess untuk media/native messaging. Bukan microservices, bukan server localhost yang membuka database untuk browser, bukan LLM bebas menjalankan OS.
Tauri mendukung Rust core dan frontend web; permission/capability membatasi jembatan UI ke core. Itu tidak melindungi dari Rust core yang berbahaya atau salah mengimplementasikan scope.[1][2]

2. STACK YANG DIREKOMENDASIKAN
  Desktop shell: Tauri 2.x; exact compatible patched releases dikunci saat bootstrap dan dicatat ADR/lockfile.
  Core: Rust stable pinned toolchain, Tokio async, Serde typed DTOs, structured tracing with redaction.
  UI: React + TypeScript + Vite, form validation schema, lightweight local state/query layer. Versi tepat dan library UI dipilih setelah spike WebView2, bukan otomatis mengejar latest.
  Storage: SQLite via rusqlite (candidate) dalam dedicated DB worker/single logical writer; migrations versioned SQL. Jangan memanggil blocking SQL/file I/O langsung pada UI thread.
  Rendering lanes: affiliate memakai AI/hybrid media adapter, bukan Blender default. Engineering 3D memilih Blender atau Three.js; Three.js scene/camera/renderer perlu pipeline deterministic frame capture/encode tersendiri sebelum disebut video exporter yang bekerja.[23][24]
  Media: FFmpeg + ffprobe sebagai reviewed sidecars atau executable yang dipilih user dan diverifikasi. Codec/build/distribution license harus ditinjau; FFmpeg tidak memiliki satu lisensi binary universal untuk semua build.[8]
  MCP: official Rust SDK rmcp sebagai kandidat, client mode stdio dan Streamable HTTP; feature/version negotiation dan dependency advisory check wajib.[5][15]
  HTTP providers: reqwest with explicit timeout, no cross-origin credential forwarding, schema validation, bounded redirects/size. Per-protocol adapter, bukan universal “semua OpenAI-compatible pasti bekerja”.
  Credentials: OS credential store melalui reviewed Rust library atau broker native; DB hanya menyimpan credential_ref. Validasi implementasi Windows saat spike; tidak mengklaim sudah aman hanya karena nama library.
  Chrome: MV3 companion extension + native messaging host Rust sebagai kandidat untuk tab user. CDP dedicated profile alternatif untuk sandbox/testing, bukan mengambil cookie profil harian.
  QA/testing: cargo test, UI component tests, disposable SQLite tests, adapter contract fixtures, E2E desktop yang kompatibel dengan WebView2; tool E2E tepat ditentukan dalam spike.
  Packaging: Windows installer + native-host registration per-user, signed release candidate setelah sertifikat/proses tersedia; signed update manifest dan rollback-safe migration.
  No default: Redis, Kubernetes, Postgres server, Docker wajib, vector DB, browser cookie importer, embedded cloud agent runtime.
Pure Rust UI (egui/Slint/iced) adalah alternatif jika user mengharuskan semua UI Rust. Pilihan Tauri adalah rekomendasi karena workspace/forms/media panels; belum perbandingan benchmark. Keputusan ini masih terbuka.

3. MODUL DAN OWNERSHIP
  ui: local bundled assets; data presentation, editing and explicit trusted approval interaction.
  application: typed commands, workspace auth/scope, optimistic concurrency/revision checks.
  domain/projects: taxonomy, product versions, claims, assets, scenes, template versions.
  domain/planning: capability resolver, prompt/compiler, source/skill version pins; LLM menghasilkan proposal saja.
  domain/workflows: graph validation, dependencies, state transitions, retries and schedule policy.
  domain/policy: effect registry, rights/release gates, grants, budget reservations, revocation.
  infrastructure/db: migrations, transactional repository, single-writer scheduling; tidak bocorkan SQL ke UI.
  infrastructure/adapters: text/media APIs, MCP client and browser adapter. Satu normalized Adapter contract.
  infrastructure/media: argv-only process launch, probe/decode, safe temp/output handling, bounded concurrency.
  infrastructure/secrets: credential lifecycle, masking, endpoint scoping, no credential dump to JS.
  operations: redacted events, recovery/reconciliation, backups/restore and dependency diagnostics.
Skill importer/read-only library tidak mengubah ~/.hermes atau profil lain. Jika skill Hermes diadopsi, snapshot bagian guidance+metadata yang ditinjau, sumber/license/revision dicatat; bukan menjalankan seluruh folder sebagai plugin.

4. DATAFLOW DAN TRUST BOUNDARY
  Local UI -> typed Tauri command -> scope validation -> domain policy -> DB transaction/outbox-like intent -> adapter -> exact provider/Chrome/MCP route -> validated response -> asset filesystem -> QA -> export.
  Renderer tidak mendapat credential provider. Remote HTML tidak dimuat ke privileged Tauri WebView; referensi situs dibuka di browser eksternal atau ditampilkan sebagai sanitized text.
  UI state tidak menjadi otoritas biaya; grant disimpan dan dikonsumsi di core. Prompt/hasil model/seller text/tool descriptions adalah data tidak tepercaya.
  Three.js scene preview dari authoring code ditempatkan dalam konteks isolated tanpa privileged Tauri IPC; script yang dihasilkan AI tetap untrusted sampai ditinjau. Blender Python juga tidak memperoleh hak OS tambahan hanya karena dibuat AI.
  Core menolak arbitrary filesystem path, executable, shell arguments, origin/endpoint dan network targets yang tidak disetujui. Signed/allowlisted adapter binary tetap bukan sandbox; executable MCP membawa risiko hak OS.
  Native host ke core memakai named pipe per-user dengan restrictive ACL, pairing token dan session binding; desain ini harus diuji, bukan menganggap native messaging langsung mencapai proses desktop yang sedang berjalan.
  One writer per browser tab/project; lease memiliki expiry, connection epoch dan fencing token; stale worker ditolak.

5. CHROME INTEGRATION DECISION
Chrome native messaging mendefinisikan host manifest, allowed_origins dan framing JSON; transport ini untuk kontrol/metadata, bukan pengiriman file video besar. Extension memulai koneksi; app tidak dapat seenaknya mengirim ke semua tab Chrome.[3]
Google mendokumentasikan perubahan sejak Chrome 136: remote-debugging flags tidak berlaku pada default data directory; custom user-data-dir diperlukan untuk jalur itu. Karena itu “otomatis attach ke Chrome harian via port” bukan asumsi yang sah.[4]
Mode M0: read-only/manual-assisted. User memilih satu tab+domain dan consent; koneksi dapat menampilkan URL/model/selected assets yang boleh dibaca. Tidak auto-login, tidak cookie export, tidak full HAR.
Setelah gate: site-specific Flow adapter dengan versioned selectors dan prepare/readback, sebagai route pertama M0 jika dipilih atau ekspansi M1. Sebelum gate lolos, browser tetap read-only/manual-assisted. Koneksi umum Chrome tidak membuktikan Flow adapter dapat mengunggah aset atau generate aman.
CDP dedicated profile tetap opsi testing. Dokumentasi Chrome juga menyediakan existing-session auto-connect pada Chrome 144+ dengan --autoConnect, remote debugging yang diaktifkan user dan dialog izin Chrome. Jadi existing session tidak mustahil, tetapi akses sesi luas memerlukan review khusus dan tidak membuktikan isolasi per-tab.[20]
Native extension tetap kandidat default untuk scope tab yang terkontrol; pilih satu controller saja. Jangan disable browser security untuk mengejar akses.
Native host registration/unregistration, upgrade paths dan extension distribution membutuhkan spike Windows sebelum keputusan final.

6. CAPABILITY-BASED ROUTING
Candidate route = provider instance(account alias + surface + endpoint) + exact model identifier/observed UI label + adapter revision + capability evidence.
Hard constraints: media/reference kind and count, combination support, size/duration/aspect, product fidelity strategy, rights/scope, account eligibility, budget/quote, region/plan, upload consent.
Soft preferences: cost, estimated latency, quality preference. Tidak memilih cheapest route sebelum hard constraints lolos.
Unknown != unsupported != verified. Declared/manual/documented/observed/fixture/live verification dibedakan. Bukti expired atau scope berubah memerlukan revalidation.
Google Flow menyatakan fitur bergantung pada model dan subscription; aktif model, resolution dan credit cost perlu diperiksa sebelum generate. Karena itu katalog lama atau API capabilities tidak membuktikan UI account tertentu mendukung kombinasi aset.[18]
Routing tidak auto-fallback saat error, tidak transfer native asset ID antarprovider dan tidak menjumlahkan saldo credits lintas vendor.

7. EXECUTION / RECOVERY
  Local deterministic node -> bounded retry hanya jika proses sebelumnya dipastikan berhenti dan output temp belum dipromosikan.
  Remote effect -> persist stable intent, canonical request hash, single-use grant dan reservation dalam satu transaksi sebelum dispatch.
  Crash before dispatch record sent: recovery konservatif; jika mungkin sudah keluar, UNKNOWN, reconcile dahulu. Local DB tidak memberi provider exactly-once delivery.
  Event cursor memungkinkan UI reconnect/reload tanpa mengulang run. Duplicate command dengan key sama/payload beda = IDEMPOTENCY_CONFLICT.
  Concurrent run dibatasi setting dan resource checks; MVP default satu media job berat. Itu policy konservatif, bukan angka kapasitas hardware terukur.
  Output ditulis ke temp dalam workspace, diverifikasi hash/probe/decode, lalu atomic rename pada filesystem yang sama. Database merujuk artifact yang sudah ada; janitor menandai missing/orphan, tidak menghapus otomatis tanpa retention policy.

DATABASE DESIGN — v0.2
Status: schema usulan, bukan database aplikasi produksi. File SQL dapat diuji pada DB disposable.

1. PILIHAN DAN LOKASI
SQLite metadata + filesystem untuk media. Ini untuk satu operator lokal dengan satu logical writer, bukan shared DB di network drive. Runtime root yang diusulkan: %LOCALAPPDATA%/CreatorDesktop/workspaces/<workspace-id>/.
  db/workspace.sqlite
  assets/<asset-id>/<revision>/<safe-filename>
  artifacts/<run-id>/<node-id>/<artifact-id>.<extension>
  evidence/<evidence-id>/...
  cache/ dan temp/ dapat dibersihkan sesuai policy, bukan source assets.
  logs/ redacted dengan retention yang disetujui.
Folder rencana yang berada di OneDrive bukan lokasi runtime yang disarankan.
Foreign keys harus diaktifkan pada setiap koneksi; SQLite menjelaskan enforcement FK bersifat per-connection dan tidak boleh diasumsikan aktif dari default.[6]
WAL adalah opsi saat implementasi setelah runtime patch/compatibility diperiksa. Dokumentasi SQLite saat diambil mencatat WAL-reset bug diperbaiki pada 3.51.3 dan beberapa backport. Jangan menyamakan dukungan SQL STRICT dengan versi yang aman untuk semua pola WAL.[7]
DDL ini tidak mengaktifkan WAL dan tes utama menggunakan DB disposable. Exact bundled SQLite akan diverifikasi terpisah dari versi Python fixture.

2. LOGICAL ERD / KELOMPOK
Configuration: providers -> model_routes -> capability_snapshots; connections -> scoped observations.
Recipes: skill_versions <- workflow_skills -> workflow_versions <- template_versions.
Content: projects -> project_products -> product_versions -> products; product_versions -> evidence -> claims.
Assets: assets -> asset_versions; scenes -> scene_assets -> asset_versions; scenes -> scene_claims -> claims.

Full FK relationship diagram di diagrams/database-full.mmd dihasilkan dari SQLite PRAGMA, bukan digambar ulang dari ingatan. Visual kelompok yang lebih terbaca ada di diagrams.html.

4. REPRESENTASI DAN INVARIANTS
ID: application-generated opaque UUID string. Fixture tests memakai ID pendek yang sengaja synthetic. PK SQLite tidak membuktikan format UUID; parser app wajib.
Time: epoch milliseconds UTC INTEGER; UI menampilkan locale dan timezone. Expiry memakai trusted core clock, bukan teks model.
Money: IDR integer minor-unit convention dengan currency metadata yang benar; vendor credits integer amount_u + unit_scale dari wallet. Jangan float untuk accounting.
Hash: lowercase SHA-256 raw source/canonical serialization bytes; snapshot canonicalization version dipin. Sumber normalized text diberi format berbeda, tidak dianggap raw file digest.
JSON: json_valid checks syntax saja; DTO JSON schema/business rules diuji core. Required asset limits, DAG acyclic dan valid output aspect bukan otomatis benar karena JSON valid.
Deletion: FK default RESTRICT/NO ACTION untuk history. Archive/disable/revoke daripada cascade. Penghapusan workspace eksplisit memerlukan confirmation+backup policy; evidence/history berisi data sensitif dan harus dapat diekspor/dihapus sesuai pilihan user dan kewajiban yang relevan.
Integrity subset di DB: FK, enum/check, one-primary product, immutable versions/bytes/request, evidence product match, product scene scope, template/workflow match, receipt/grant match, single-use approval/intent uniqueness, reservation scope/cap.
App invariants yang masih wajib: authorized OS/operator action, canonical hash benar, live readback freshness, required inputs/rights/consent, full state transition validity, current claims/assets revocation, budget ledger reconciliation, no arbitrary path/network/secret injection, immutable scene binding after finalization, no secret values in JSON.
SQL path checks hanya baseline. App harus reject symlink/junction/reparse-point escape, absolute/UNC/device paths, traversal after decoding, reserved names dan alternate data streams; tidak menganggap CHECK relpath sebagai filesystem sandbox.

5. WORKLOAD DAN INDEX ASSUMPTIONS
Workload awal: operator membuka catalog, recent projects/runs, scenes, pending jobs/UNKNOWN intents dan event tail. Volume nyata belum diketahui; belum ada throughput/size benchmark.
Indexes awal mengikuti lookup tersebut; jangan menambah FTS/vector database sebelum kebutuhan pencarian dan biaya indexing terukur. Reference index sudah ada pada project time, run/project, node state, intent state, event cursor, asset hash dan capabilities.
Large blobs tidak disimpan ke SQLite. Metadata JSON bounded di app. Media cache/temp punya retention policy dan kebutuhan free-space checks.

6. TRANSACTION SKETCH
BEGIN IMMEDIATE;
  Verify immutable run/node/revision/request+receipt and current consent/rights.
  Claim stable intent key; same key different body rejected.
  Verify grant exact hash+effect+scope+expiry, not consumed/revoked.
  Conditional budget UPDATE ... WHERE reserved+spent+new_amount <= limit;
  Insert intent (trigger consumes grant), insert reservation, append redacted event;
COMMIT;
Only then call adapter. No cross-provider transaction/exactly-once promise. On possible dispatched failure keep intent UNKNOWN and reservation intact until reconciliation.
If any preflight/insert fails, rollback counters+intent+grant consumption together. Actual provider cost can exceed an estimate externally; stop scheduling, surface variance and reconcile actual spend, never silently under-report to satisfy local CHECK.

7. MIGRATION / BACKUP / RESTORE
Migrations run while scheduler stopped and no native host writer active; check schema version and app compatibility first. Backup consistent DB before destructive migration.
Use SQLite backup API or reviewed consistent snapshot method, plus assets/evidence/artifacts manifest under a paused/quiesced workspace. Copying workspace.sqlite alone while WAL writer is active is not accepted backup design.
Restore defaults dry-run to a new root; reject path escapes, verify every included file/hash, apply schema check, PRAGMA integrity_check/foreign_key_check, then open read-only preview before switching active root.
Secrets/browser profiles/session/cookies excluded; model/provider configs restore disabled until credential rebind and connection validation. Target path and dependencies resolved anew.

08-PRODUCTION-LANES

PRODUCTION LANES — USER DIRECTION ADDENDUM v0.2
Status: plan-only. Tidak mengizinkan install, generation, upload atau pemakaian kredit.

KEPUTUSAN EDITORIAL
Affiliate product memakai jalur AI-assisted/hybrid sebagai default, bukan Blender. Istilah “tree.js” dari percakapan ditafsirkan sebagai Three.js; ejaan library yang dipakai dalam desain adalah Three.js, bukan library pembuat pohon.
3D engineering memakai structured scene pipeline Blender atau Three.js sesuai kebutuhan, bukan memaksa semua video menjadi text-to-video.
Addendum ini menggantikan rekomendasi editorial v0.1 bahwa real-footage composition harus menjadi satu-satunya jalur awal. Real footage tetap opsi dan bukti penting untuk klaim penggunaan/demonstrasi nyata. Perubahan prioritas editorial tidak membuktikan adapter generatif telah terpasang atau bekerja.

LANE A — AFFILIATE AI / HYBRID
Produk/varian + fakta/evidence + foto/video berizin -> AI script/storyboard -> reference-conditioned image/video generation atau generated background/B-roll -> authorized product composite bila diperlukan -> voice/captions -> composition -> product-fidelity/audiovisual QA -> export.
Produk tidak boleh berubah merek/label/warna/varian/geometri penting. Jika generative route tidak mempertahankannya, gunakan canonical product layer/footage asli atau BLOCKED; jangan menganggap video yang tampak menarik sebagai demonstrasi faktual.
AI human/host tidak boleh mengarang testimonial pemakaian. Pernyataan “lebih diterima audiens” adalah hipotesis kreatif yang perlu pilot dan data actual, bukan acceptance teknis yang sudah terbukti.
Default ini tidak menjadikan foto/video produk wajib diambil sendiri apabila tersedia izin yang memadai; link seller saja tetap bukan izin reuse.

LANE B — ENGINEERING 3D
Blender direkomendasikan untuk authoring/animation dan offline rendered output dari scene terstruktur. Dokumentasi resminya menjelaskan animation frames dan pendekatan frame sequence untuk finishing video.[24]
Three.js menjadi kandidat untuk scene/diagram/animasi procedural dan preview interaktif di lingkungan web. Manual resminya menggunakan scene, camera dan renderer; ini bukan jaminan exporter MP4 desktop siap atau compatibility WebView2/GPU telah diuji.[23]
Pilih satu pemilik renderer per shot. Lane Three.js memerlukan desain deterministic timing/frame capture + encode dan smoke test tersendiri. Blender dan Three.js tidak otomatis menggantikan CAD/engineering solver atau membuktikan mekanisme benar.
AI coding worker dapat membantu membuat script Blender atau Three.js; AI authoring tidak berarti output shot dibuat oleh video model generatif.

LANE C — GENERAL / SHORT
Pilih AI generatif, authorized footage, motion graphic atau structured 3D berdasarkan brief. SHORT adalah format, bukan engine. Jangan merutekan semua short ke satu renderer.

BATAS TEKNIS YANG TETAP BERLAKU
Satu exact AI video route harus melewati connection/capability/reference/quote dan reconciliation spike sebelum disebut operasional. Metadata connection atau menu model bukan bukti generation bekerja.
Upload/generation membutuhkan persetujuan sesuai efek dan biaya; tidak ada silent fallback atau penggunaan kredit otomatis.
Finishing/export terpisah dari engine pencipta scene; QA dan disclosure platform tetap wajib diperiksa.
Baseline publikasi v0.2 mengikuti keputusan ini: satu exact AI/hybrid video route adalah MVP gate, sedangkan engineering 3D Blender/Three.js tetap lane terpisah. Tidak ada klaim app implemented.
